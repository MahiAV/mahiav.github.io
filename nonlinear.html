NONLINEAR LOW-RANK LEARNING · PREPRINT

A Local Theory of Gradient-Based Rank-One Recovery in Nonlinear Low-Rank Models

We studied how a model’s gradient can guide its next low-rank update.

Mahtab Alizadeh Vandchali, Fangshuo Liao, Anastasios Kyrillidis

Read the preprint PDF · 17.3 MB ↗

Learning what the model is missing

Sequential low-rank methods build an update one rank-one component at a time. In a linear model, the gradient can show what the model still needs to learn—the residual. With a nonlinear activation, that signal is less direct.

We studied this question in a single-layer Leaky-ReLU model with Gaussian inputs. The scaled gradient contains the residual plus two sources of error: nonlinear bias and sampling noise. To recover a useful direction, these errors must be small compared with the gap between the residual’s leading singular values.

Scaled gradient=Residual+Nonlinear bias+Sampling error

Select, fit, then freeze

  1. Select a direction. Take the leading left and right singular vectors of a scaled gradient computed on a fresh batch.
  2. Fit one amplitude. Keep these directions fixed and refine a single scalar controlling the size of the update.
  3. Freeze and repeat. Add the fitted rank-one component, then compute the next gradient from the updated model.

Under the theory’s local assumptions, the final error has two parts: components that have not yet been learned, and errors accumulated during earlier updates. Each step adds one rank, so a single run produces models of increasing rank. Choosing when to stop without knowing the target rank remains an open question.

Scope of the guarantees

The local recovery results assume Gaussian inputs, one Leaky-ReLU layer, fresh batches, sector control, and separated oracle singular values. They analyze fixed directions with scalar fitting. Deep-network convergence and bounds on free-factor rotation remain open.

The memory benefit concerns active optimizer state. It does not imply reduced total memory, gradient computation, or storage of accumulated updates. Synthetic experiments examine the per-stage diagnostic; frozen-feature image experiments explore an additional connection to active-state memory.
